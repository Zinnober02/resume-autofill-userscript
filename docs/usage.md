# 使用说明

装一次，以后在任何企业招聘官网的申请表页面，点一下右下角的「填表」按钮，姓名、手机、邮箱、学校、专业、学历、实习经历、自我评价这些就自动填好了。

资料只存在你自己电脑的浏览器里，不会上传到任何地方。脚本也不会替你点提交。

脚本里没有任何个人信息。你的姓名、电话、邮箱、学校这些只存在两个地方：你自己浏览器里的 Tampermonkey 存储，以及你自己维护的 `我的资料.json`。

## 一、装浏览器扩展（只做一次）

1. Chrome 或 Edge，打开扩展商店，搜索 **Tampermonkey**（中文名「篡改猴」），安装。
2. 装完浏览器右上角会多一个黑色小图标。

## 二、装脚本

最简单的方法：打开仓库里的 `dist/resume-autofill.user.js`，Tampermonkey 会弹出安装页，点「安装」就行。也可以把这个文件直接拖进浏览器窗口。

如果拖拽没反应，就手动来：

1. 点 Tampermonkey 图标 → 「管理面板」→ 顶部那个「+」新建脚本。
2. 用编辑器打开 `dist/resume-autofill.user.js`，全选复制。
3. 粘贴进去覆盖掉原来的内容，按 Ctrl+S 保存。

## 三、开始用

> **第一次用之前先做一件事**：脚本刚装好时里面没有任何资料，请先按下面「四、怎么改资料」填一次，之后所有网站就都能用了。

1. 打开企业招聘官网的在线申请表页面。
2. 右下角会出现蓝色的「填表」按钮；没出现就按 **Alt+Shift+F**。
3. 点「一键填充本页表单」。
4. 页面上填好的字段会闪一下绿框。面板下方还会列出：已经填好了哪些、哪些需要你手动处理、哪些字段脚本没认出来。

> 提交前请务必自己扫一眼，尤其是日期、薪资、下拉框这几类。

## 四、怎么改资料（重点）

资料默认是空的，第一次要你自己填一次。有两种方式，怎么顺手怎么来。

**方式 A：在网页里直接改**

点面板上的「编辑资料」，按分组改完，点「保存并返回」，立刻生效。

**方式 B：改 `我的资料.json`**

把 `examples/profile.example.json` 复制一份，改名成 `我的资料.json`，用编辑器打开改完保存（**一定要存成 UTF-8 编码**）。回到网页，点「载入资料文件」，选中这个 json，就覆盖进去了。

> 手改 json 最容易遇到的问题：少写或多写一个逗号、引号没配对、漏掉一个字段，文件就会读不进去（网页上会弹提示）。更稳妥的做法是平时就在网页面板里改，改完点「导出资料文件」生成 json，不用手动编辑。

反过来也行：网页里改完，点「导出资料文件」，浏览器会下载一份新的 json，拿去覆盖你自己那份，就是最新的备份。

> 建议：把 `我的资料.json` 和简历放在一起用 git 管起来，每次更新简历之后顺手改一次再「载入资料文件」。这个文件里有你的个人信息，不要提交到公开仓库。

## 五、多套方案（针对不同岗位）

面板顶部有个下拉框，可以放好几套资料，比如：

- AI 应用 / Agent 方向
- 后端开发方向
- 国央企方向

点「复制一份」就会以当前方案为模板建一套新的，改改意向岗位、意向城市就行。投递时先切到对应的方案，再点一键填充。

## 六、认不出来的字段，怎么加规则

每家官网的叫法都不一样，总会有几个脚本不认识的。它们会出现在「没认出来的字段」列表里，比如显示 `期望岗位`。

处理办法：点「编辑资料」→ 拉到最底部「补充规则」→「+ 加一条」：

| 左边（网页上那个字段旁边的文字） | 右边（要填进去的内容） |
| --- | --- |
| 期望岗位 | AI应用工程师 |
| 是否服从调剂 | 是 |

保存后再点一次「一键填充」就好了。加的规则会跟方案一起保存，之后所有网站碰到这个叫法都会自动填。

## 七、已经能认出来的常见叫法

**基本**：姓名 / 中文姓名 / 申请人姓名、英文名 / 拼音、性别、出生年月 / 出生日期、民族、政治面貌、婚姻状况、身份证号 / 证件号码、手机 / 联系电话 / 联系方式、邮箱 / E-mail、微信号、籍贯、户口所在地、现居城市 / 所在城市、通讯地址 / 详细地址、邮编

**求职**：应聘职位 / 意向岗位 / 期望职位 / 求职意向、期望城市 / 工作地点、期望薪资、到岗时间 / 入职时间、获知渠道、个人网站 / 博客、GitHub / 开源

**教育**：毕业院校 / 学校名称、学院 / 院系、专业 / 专业名称、学历 / 最高学历、学位、GPA / 绩点、排名、学校所在地、入学时间 / 开始时间、毕业时间 / 结束时间

**工作**：公司名称 / 工作单位、部门、职位 / 职务 / 岗位、入职时间、离职时间、工作内容 / 职责描述、项目描述

**其他**：紧急联系人（姓名 / 与本人关系 / 电话）、自我评价 / 自我介绍 / 评价内容、专业技能

**证件与身份**：证件类型 / 证件类别、身份证号 / 证件号码、户口类型 / 户口性质、高考生源地 / 生源地、健康状况、是否应届毕业生

**求职补充**：期望工作性质 / 工作类型、是否服从调剂 / 岗位调剂、内推码、了解该招聘信息渠道

**语言、技能与爱好**：英语水平 / 英语等级、其他外语水平、IT 技能掌握程度 / 计算机等级、个人爱好

**证书、专利、论文、奖励、家庭关系**：这几类按区块识别，区块内的「名称 / 类型 / 时间 / 等级 / 作者排序 / 关系」等字段都能对上；资料里也都是一段一张卡片。

除了中文，也会看输入框的 `name` / `id` / `placeholder` / `autocomplete` 里的英文，比如 mobile、email、school、major、company、position、graduation 等。

**教育经历分几段也不会乱**：如果表单里分了「本科 / 硕士」两行，脚本会分别填对应的学校专业；没写「本科 / 硕士」的，就按从上到下的顺序，第一段当最高学历、第二段当本科。

## 八、日期、时间与「添加」按钮

**日期与时间**

- 原生日期控件（`type=date`、`type=month`）按控件要求的格式填写。资料里的日期都写到日，只收年月的控件会自动截断：提示文字写成 `YYYY-MM` 或 `yyyy/mm` 的按月填，字段名带「年月」的按月填，`maxlength=7` 的按月填，其余按日填。
- 时间控件（`type=time`、`type=datetime-local`）需要具体时刻。资料里只有年月日时，脚本会把这个字段列进「需要手动处理」，不会写一个控件接受不了的值。
- 年、月、日 分成三个下拉框或者三个输入框的表单，脚本会把整组一起填好。
- 组件库的日期选择器（antd、element-ui、iview、arco 这类只读输入框加弹层）会点开弹层，逐级选中目标年、月、日。
- 同一块里有开始与结束两个时间时，先填开始时间，再填结束时间。

**点「添加」才出现的编辑框**

- 页面上一出现新的编辑框（点「添加」新增的经历区块、弹出的对话框），脚本会自动按当前方案填一次，不需要再点「一键填充」。这个行为可以在面板上关掉。
- 资料里可以放多段教育经历和工作经历：在「编辑资料」页面拉到「多段教育经历」「多段工作 / 实习经历」，一段一个卡片，可以随时加一段、删一段。留空时仍然按上面「教育经历」「工作 / 实习经历」里的字段填。
- 打开面板上的「资料里有几段经历就自动点「添加」补几段」之后，脚本会按资料的段数点击页面上的「添加」按钮，把区块补足再填。这个开关默认关闭，因为它会改动页面内容，只在需要的时候打开。
## 九、需要你手动的地方

- **上传简历附件**：浏览器安全限制，脚本没办法替你选文件，会把它标出来提醒你。
- **登录、短信验证码**：先自己登录，登录后再点填充。
- **部分定制下拉框**：比如「省 / 市 / 区」三级联动、学校搜索联想框。脚本会尝试自动选，选不上会在「需要手动处理」里提示你。
- **没适配到的日期控件**：市面上组件库很多，脚本按常见的几套类名适配。弹层结构对不上的，会在「需要手动处理」里提示你，不会再出现「报告填好了、页面上却是空的」这种情况。
- **日期精度**：资料里的日期写到日。遇到只收年月的控件（`type=month`、提示文字写成 `YYYY-MM`、字段名叫「出生年月」、或者 `maxlength=7`）会自动截到月，不会多填一个日。
- **薪资、到岗时间**：这两项通常要按公司情况现场定，可以留空，想自动填就先写进资料里。

## 十二、升级与自己改规则

- **升级**：脚本头部写了 `@updateURL`，Tampermonkey 会定期检查新版本，也可以在管理面板里点「检查更新」。资料存在浏览器里，跟脚本是分开的，升级脚本不会丢资料。
- **临时加规则**：用面板里的「补充规则」，改完立刻生效，适合只在自己电脑上用。
- **改字段识别规则**：编辑 `src/core/rules.js` 里的规则表，然后执行 `npm run build`，再把 `dist/resume-autofill.user.js` 重新装一次。
